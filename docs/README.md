# Documentación de BancoLab

BancoLab es una plataforma bancaria digital basada en microservicios. Permite a los clientes consultar el tipo de cambio, ver su información en la pantalla de inicio de la app, realizar pagos y hacer transferencias interbancarias.

La plataforma está diseñada para operar con alto tráfico, tolerar fallas de servicios externos, evitar cobros duplicados y garantizar la consistencia de las transacciones.
