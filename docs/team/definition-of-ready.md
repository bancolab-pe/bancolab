# Definition of Ready (DoR)

Un ticket está **listo para empezar** cuando cumple todo lo siguiente:

## Checklist

- [ ] **Título claro**, que se entiende sin explicación adicional.
- [ ] **Descripción** que explica qué se necesita y por qué.
    - Si es una historia: escrita como *"Como [usuario], quiero [algo], para [beneficio]"*.
- [ ] **Criterios de aceptación** definidos: cómo sabremos que está terminado.
- [ ] **Épica** asignada.
- [ ] **Componente** asignado (qué parte del sistema toca).
- [ ] **Etiqueta de perfil** asignada (`DEV`, `DEVOPS` o `QA`).
- [ ] **Estimado** en story points (a partir del Sprint 1, solo historias).
- [ ] **Sin bloqueos**: no depende de otro ticket que aún no está terminado.

## Si no cumple

El ticket vuelve al backlog para completarse en el refinamiento. No entra al sprint.
